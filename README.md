# Musha — 职业系统重制版

**穆莎 (Musha)** 是《饥荒：联机版》(Don't Starve Together) 的角色 mod，主打多职业 RPG 成长系统。

> *"你会知道我的厉害的！"* — 穆莎

---

## 特性

- **多职业转职** — 四大基础职业：战士 / 法师 / 游侠 / 刺客
- **进阶职业** — 剑士 / 近卫 / 药剂师 / 元素法师 / 吟游诗人 / 月影猎手
- **等级成长** — 等级越高，能力越强
- **技能书系统** — 通过学习技能书获取专属技能
- **武器技能** — 剑士专属「剑气斩」：右键瞄准、点地释放
- **每日任务 + 礼包** — 每日任务自动发放；游戏时间礼包与节日礼包
- **职业皮肤** — 部分职业支持专属外观皮肤（可配置开关）
- **开局指引** — 自带便签，新手上手无忧

## 配置选项

| 选项 | 说明 |
|------|------|
| 启用休息技能 | 开启后所有职业可用「休息」（怀旧功能） |
| 显示职业皮肤 | 角色根据职业显示专属皮肤（需房主设置） |
| 每日任务数量 | 每天发放的日常任务数（3 悠闲 / 4 标准 / 5 充实） |

## 安装

### 方法一：Steam 创意工坊

在 Steam 创意工坊搜索 **Musha** 订阅即可。

### 方法二：手动安装

将本仓库下载后放入 DST mods 目录：

```
Don't Starve Together/mods/musha/
```
