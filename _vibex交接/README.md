**只放记录，不动 mod 代码、不打包、不进工坊。**
目的：musha 面板这摊活要在两个 AI 之间交接 —— VibeX 干活时把「错误 / 分区 / 技能」写进来，
本体的我回来读这份记录继续分析。**写在别处的结论等于没写**（我读不到你的聊天记录）。

## 四条规矩
1. 只写这个文件夹；写结论别只写在聊天里。不存二进制、不放大图（截图给路径就行）。
2. 文件名固定 `<编号>_<简述>.md`，编号三位递增（001_、002_…），别改别人的编号。
3. 每条记录必须五段齐全：**现象 / 复现 / 结论 / 改了哪个文件第几行 / 验证结果**。
   缺复现步骤的记录，我下次读不懂。
4. 分区名统一用这十个词：
   `主页 / 技能 / 信箱 / 设置 / 礼包 / 图鉴 / 导航 / 任务列表 / 关闭按钮 / 底图框`
