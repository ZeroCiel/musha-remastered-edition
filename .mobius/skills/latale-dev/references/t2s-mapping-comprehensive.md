## Python批量替换模板

```python
T2S = {
    # 单字映射（从上面表格选择需要的）
    '愛':'爱', '麗':'丽', '絲':'丝', '戰':'战', ...
    # 双字词映射（优先）
    '經驗':'经验', '裝備':'装备', ...
}

with open('file.xls', 'rb') as f:
    data = bytearray(f.read())

count = 0
for tw, cn in T2S.items():
    twb = tw.encode('gbk')
    cnb = cn.encode('gbk')
    n = data.count(twb)
    if n > 0:
        data = data.replace(twb, cnb)
        count += n

with open('file.xls', 'wb') as f:
    f.write(data)

print(f'{count}处替换')
```

## 适用文件

| 文件 | 类型 | 替换方式 |
|------|------|---------|
| SAVEPOINT.xls/SAVEPOINT.LDT | 储存点对话 | 二进制GBK替换安全 |
| GLOBAL_STRING.xls | 系统消息 | 注意`\\n`存储为`5C 6E`双字节 |
| SKILL_TXT.xls | 技能描述 | 二进制GBK替换 |
| NPCTALK.xls | NPC对话 | 二进制GBK替换 |
| QUEST.xls/QUEST_2.xls | 任务文本 | 二进制GBK替换 |
| MAPEVENT.LDT | 地图事件文本 | 部分表可直接二进制替换 |
