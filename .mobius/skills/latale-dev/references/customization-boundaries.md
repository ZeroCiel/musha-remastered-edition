# 彩虹岛私服改端能力边界

## 核心原则

彩虹岛私服修改分三类：**LDT/SPF能做的**、**exe/GS协议锁死的**、**数据库能做的**。

改之前先判断属于哪一类。不要花时间试 exe 层面的改动。

## ✅ LDT/SPF 能做（放心搞）

| 类别 | 具体内容 | 涉及文件 |
|------|---------|---------|
| 道具 | 新增/修改装备、时装、消耗品、材料 | ITEM_*.LDT |
| 商城 | 上架/下架、改价格、分类、时限 | CASH_SHOP.LDT, CASH_PRICE_RATIO.LDT |
| NPC商店 | 新增/修改贩卖内容 | NPCTRADE.LDT, NPCTRADE_DETAIL.LDT |
| 任务 | 新增/修改任务、奖励、任务链 | QUEST_*.LDT, QUEST_REWARD_*.LDT |
| BUFF/效果 | 修改效果数值、描述 | EFFECT.LDT |
| 地图定义 | 传送点、刷怪配置、地图名 | SERVER_MAP.LDT, CLIENT_MAP.LDT |
| 地图资源（贴图） | 替换场景贴图、背景图 | SPF解包后的PNG |
| 界面贴图 | 按钮、背景、图标 | BARY.SPF/BANX.SPF内的图片资源 |
| 活动 | 时间、类型配置 | EVENT_CHECK.LDT, GLOBAL_EVENT.LDT |
| 创角赠送 | 出生送物品、技能 | CREATION_INFO.LDT |
| 经验表 | 升级所需经验值曲线 | EXPERIENCE.LDT |
| 怪物 | 怪物属性、掉落 | MOBBASE.LDT, MOBARRANGE.LDT |

## ❌ exe/GS协议锁死（不要碰）

| 类别 | 原因 | 替代方案 |
|------|------|---------|
| 时装幻化 | 需要exe实现"外观槽≠装备槽"的渲染逻辑 | 时装直接当真装备穿 |
| 武器独立外观 | S2无独立武器时装栏，武器和真武器同槽 | 做带属性的玩具武器 |
| 选人界面UI | 渲染逻辑在exe，SPF/banx只存贴图 | 可换贴图，不能改布局/交互 |
| 地图地形/碰撞 | 3D碰撞、地形生成在exe的二进制文件里 | 能换贴图，不能改地形 |
| 新增地图区域 | 需要exe支持新地图的加载和渲染 | 不可行 |
| S2→S3升级 | GS和客户端exe协议有差异 | 工作量≈重搭私服 |
| 角色动作/表情 | 动画在exe和特定资源文件里 | 不可行 |
| 连接协议 | "现在无法连接"通常是exe残留死代码 | 不影响游戏功能 |
| 商城UI布局 | 商城界面布局在exe | 可改图标，不能改交互逻辑 |

## 🤔 数据库能做

| 类别 | 说明 |
|------|------|
| 角色属性修改 | 等级、金币、点券 |
| 背包道具 | 增删物品、改数量 |
| 账号管理 | 创建/删除角色、权限 |

## 判断流程

```
问：我要改的东西属于哪类？
  ↓
先想：这是"数据或内容"还是"逻辑或渲染"？
  ├─ 数据/内容 → LDT/SPF层，直接搞
  │   例子：加道具、改任务奖励、换地图背景
  │
  └─ 逻辑/渲染 → 先问：有没有LDT字段控制？
       ├─ 有 → 试改LDT（如改BUFF数值）
       └─ 无 → exe硬编码，放弃
            例子：幻化系统、选人界面交互、地图碰撞
```

## 实操案例

| 用户需求 | 判断 | 结论 |
|---------|------|------|
| "加四系乃的衣服" | ITEM_2新增道具 → LDT层 | ✅ 能加 |
| "加时装幻化系统" | 需要exe渲染逻辑 → 放弃 | ❌ 不可行 |
| "合并他乡端地图到怀旧端" | 地图资源是SPF贴图 → LDT能换；但碰撞模型在exe → 只换贴图不改地形 | ⚠️ 部分可行 |
| "把死霸装改成时装" | ITEM_2改_PosID/_Type → LDT层 | ✅ 能改 |
| "S2升级到S3" | exe协议差异较大 | ❌ 工程放弃 |
