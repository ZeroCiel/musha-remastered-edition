# GLOBAL_STRING.LDT 系统消息ID定位

GLOBAL_STRING.LDT 存储游戏内系统提示消息文本，全string格式（类型区全0），行大小256字节。

## 常见消息ID范围

通过彩虹岛编辑器导出为XLS后，第0列就是消息ID：

### 80011~80020：连接/登录消息
```
80011  因为玩家信息问题，连接服务器延迟。
80012  因为角色信息问题，连接服务器延迟。
80013  服务器连接延迟。
80014  服务器无回应。请稍后重新试一下。
80015  操作失败，请联络工作人员。
80016  未达App里要求的安全等级。
80017  抱歉，请稍后重新尝试。
80018  对不起，?????或已?取?品
80019  由于检测到非法行为，???后再次游戏。
80020  sndaId不同。
```

### 90001~90016：安全/密码消息
```
90001  密码键不一致。
90002  安全模式已更新。请重新登录游戏，更新安全模式。
90011  OTP 认证失败。
90012  超过了输入时间。
90013  认证键重复。
90014  由于系统错误，认证失败。
90015  不能使用特殊字元。
90016  只能输入数位。
```

### 行145~165：频道/聊天系统消息
```
[行148] [%s]获得了物品。
[行150] 找不到对方。
[行152] 现在无法连接。
[行153] 对方现在没有回应。
[行154] 坐着的状态时，不能移动频道。
[行155] 全体聊天有2秒的等待时间。
[行156] 现在不能移动频道。请稍后再试。
[行157] "%d"秒后可以移动频道。
[行158] 频道已被瘫痪或是不存在的频道。
[行159] 现在连线中的频道。请再试一次。
[行160] 彩虹岛有您更精彩~
```

## 文本在ROWID.SPF中的位置

"彩虹岛有您更精彩~" 不在任何LDT文件中，而是嵌入在 ROWID.SPF 包的二进制数据区，偏移 0xf752d2。上下文为聊天频道系统消息序列。

## 修改方式

- XLS格式：彩虹岛编辑器导出后为TAB分隔GBK文本，可直接二进制替换
- LDT格式：需编辑器导出→改XLS→写回LDT
- SPF包内文本：需解包SPF→改对应文件→重新打包
