# QUEST系统经验分析（他乡端S2）

## 文件关系
| LDT文件 | 作用 | 说明 |
|---------|------|------|
| QUEST.LDT | 任务主表(126列×3000行) | 数据区全为0/无意义，**不是这个端有效任务表** |
| QUEST_REWARD.LDT | 通用奖励表(33列×3500行) | 同QUEST.LDT，数据无效 |
| QUEST_1.LDT | 1服任务表(108列×1153行) | _Name是int32索引ID，非文字 |
| QUEST_INFO_1.LDT | 1服任务信息(29列×1607行) | **实际有效表**，含_Quest_BaseLV |
| QUEST_REWARD_1.LDT | 1服奖励(33列×1153行) | 与QUEST_INFO_1行索引对应 |
| QUEST_REWARD_2.LDT | 2服奖励(2387行) | 总经验约60B |
| QUEST_REWARD_3.LDT | 3服奖励(19行) | 总经验约3.4B |

## 关键字段说明
- **QUEST_INFO_1**._Quest_BaseLV = 任务基础等级(接取等级)
- **QUEST_INFO_1**._Quest_Kind = 任务类型(1=主线, 0=普通, 其他值未知)
- **QUEST_REWARD_1**._Reward_EXP = 经验奖励(int32, 上限2,147,483,647)
- **QUEST_REWARD_1**._Reward_Ely = 金币奖励

## 1~100级任务经验分布
| 等级 | 任务行 | 经验 | 备注 |
|------|--------|------|------|
| Lv1 | 行593 | 10,000,000 | 疑似调试/改造遗留 |
| Lv1 | 行693 | 14,900,226 | 同上 |
| Lv1 | 行729 | 1,000,000 | 同上 |
| Lv1 | 行1002 | **2,000,000,000** | **严重异常**，升到Lv150+ |
| Lv21 | 行483 | 1 | 可能是GM标记 |
| Lv32 | 行75 | 1 | 可能是GM标记 |

其他等级(Lv2~100) **任务经验全为0**。

## 结论
- 这个端没有设计1~100级任务经验系统
- 那4个Lv1的大额经验奖励是**异常值，非正常任务设计**
- 升级太快的原因是**EXPERIENCE.LDT前期曲线太低**，不是任务系统
- 改成长曲线建议：先调EXPERIENCE.LDT，任务奖励以后再说

## 编辑器_RowId说明
LDT文件本身**没有_RowId列**。彩虹岛编辑器显示的_RowId是**自动生成的虚拟列**（二进制行号，从0开始）。编辑器第一行展示的"115003000"不是RowId，而是最后一列_Reputation3(列31)的值。以此类推，按行号（非_RowId）定位即可。

## 20亿经验模板块规律
- 每34行重复一个2B模板块（行730→764→798→832→866→900→934→968→1002→1036→1070→1104）
- 每个2B块后紧跟一个约164M的行
- 这些行的_Quest_BaseLV全是乱码（负数/大值），**实际未接入游戏**
- **唯一生效的2B行=行1002**（_Quest_BaseLV=1，_Name索引=808465462）

## 修改建议顺序
1. 先备份
2. 清零异常奖励（行593/693/729/1002的_Reward_EXP→0）
3. 调EXPERIENCE.LDT曲线
4. 重启测试
5. 后续再设计任务经验体系
