# 繁转简完整映射（2026-06-07 更新）

适用于彩虹岛XLS/LDT文件的GBK二进制繁转简替换。

## Python 替换脚本

```python
T2S = {
    '愛':'爱','麗':'丽','絲':'丝','戰':'战','鬥':'斗',
    '劍':'剑','騎':'骑','遊':'游','俠':'侠',
    '龍':'龙','驗':'验','訊':'讯','帳':'账',
    '隊':'队','組':'组','體':'体',
    '後':'后','裡':'里','嗎':'吗',
    '寶':'宝','貝':'贝','貓':'猫',
    '點':'点','擊':'击','練':'练','習':'习',
    '穫':'获','確':'确','認':'认','說':'说','話':'话',
    '請':'请','問':'问','遠':'远',
    '魚':'鱼','鳥':'鸟','時':'时','間':'间',
    '儲':'储','資':'资','連':'连','線':'线',
    '裝':'装','備':'备','窗':'窗','覆':'复',
    '亞':'亚','東':'东','麵':'面','條':'条',
    '敵':'敌','殺':'杀','聲':'声','響':'响',
    '發':'发','現':'现','動':'动','畫':'画',
    '書':'书','記':'记','幫':'帮','助':'助',
    '總':'总','會':'会','風':'风','雲':'云',
    '萬':'万','歲':'岁','樂':'乐',
    '從':'从','擁':'拥','關':'关','開':'开','於':'于',
    '與':'与','並':'并','個':'个','將':'将',
    '卻':'却','為':'为','還':'还','夠':'够','麼':'么',
    '這':'这','幹':'干','哪':'哪','兒':'儿','牠':'它',
    '們':'们','來':'来','帶':'带','爾':'尔','聽':'听',
    '盡':'尽','頭':'头','邊':'边','變':'变','處':'处',
    '對':'对','産':'产','業':'业','務':'务',
    '報':'报','告':'告','筆':'笔','本':'本',
    '關':'关','係':'系','進':'进','步':'步',
    '僅':'仅','限':'限','歡':'欢','迎':'迎','謝':'谢',
    # 第二批次发现的遗漏（SAVEPOINT.xls二轮验证发现）
    '經':'经','歷':'历','險':'险','領':'领','稱':'称','礦':'矿',
    '蕭':'萧','蹤':'踪',
}

with open('file.xls', 'rb') as f:
    data = bytearray(f.read())

count = 0
for tw, cn in T2S.items():
    n = data.count(tw.encode('gbk'))
    if n > 0:
        data = data.replace(tw.encode('gbk'), cn.encode('gbk'))
        count += n

print(f'替换: {count}处')

with open('file.xls', 'wb') as f:
    f.write(data)
```

## 注意

- **不需映射的字**：回/助/存/什/迎/本/告/步/域/冒 — 繁简GBK编码相同，替换会跳过
- **SAVEPOINT.xls实测**：44列，两轮共约1166处替换
- 备份原文件：`cp file.xls file.xls.bak`
- XLS是TAB分隔的GBK文本文件，二进制替换安全
- LDT文件不等长替换会破坏结构导致GS闪退，仅限等长替换
