# 服务端exe版本对比

不同彩虹岛端的exe体积和md5差异很大，混用会导致野外同步异常（怪掉下来、打怪无伤害、掉线）。

## 已知版本特征

| exe | 大小 | 说明 | 客户端exe大小 |
|-----|------|------|--------------|
| `LataleGameServer.exe` | ~2.6MB | 普通端/怀旧端GS，通用名 | ~3.8MB（他乡端客户端） |
| `Latalegameserver_101.exe` | ~2.6MB | 同上，带后缀读`[LataleGameServer_101]`节 | ~3.8MB |
| `LataleGameServer101.exe` | ~4.0MB | **他乡端GS**，可能是独立版本或带保护壳 | ~3.8MB |
| `GameServer101.exe` | ~2.0MB | S1端GS（2016年版） | ~6.9MB（2012年客户端） |

## 野外同步异常诊断

现象：怪从天上掉下来、打怪不掉血、频繁掉线

### 排查步骤
1. 确认客户端和服务端exe是否配套（从同一个端包解压出来的）
2. 核对exe体积——体积差异大（如2.6MB vs 4.0MB）说明版本不同
3. 尝试换配套的exe：
   - 如果是他乡端GS（4MB）配他乡端客户端exe
   - 普通端GS（2.6MB）配普通端客户端exe
4. S1端（2012年客户端exe 6.9MB）与其他版本完全不兼容

### 已知结论
- 他乡端GS101（4MB）即使配对他乡端的客户端，野外也可能有问题
- 换普通端GS（2.6MB）配他乡端客户端也不能解决——要整端换
- 无配置层解决方案（SkipVersionCheck=1已设）
