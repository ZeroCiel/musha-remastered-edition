# S2 经验表 (EXPERIENCE.LDT)

## 文件位置与格式

`D:\彩虹岛\resource\ROWID\DATA\LDT\EXPERIENCE.LDT`

- 头部2列声明（`_MinXp`, `_MaxXp`），255行（Lv0~254），数据区全为0
- 实际经验值存储在文件尾部（偏移8722~END），以二进制：
  `[4B level_idx] [4B 0x10000000] [ASCII数字 exp_value] [1B 0x20空格]`
- 文件末尾以 `END  ` 标记结束
- 经验值是**累计经验**（升到该级所需的总经验）

## 修改策略（延长前期成长时间）

### 策略A：拉高前中期（Lv1~100）+ 平滑过渡
- Lv1~50：每级经验乘以系数2~3倍
- Lv50~100：系数逐渐降低从2倍到1.2倍
- Lv100+：保持不变

### 策略B：分段常数增长
- Lv1~10：每级固定10,000
- Lv11~30：每级固定50,000
- Lv31~50：每级固定200,000
- Lv51~70：每级固定1,000,000
- Lv71~100：按原表

### 策略C：公式化重写
- exp(n) = 3000 × n^1.5

## QUEST_REWARD_1.LDT也是特殊格式
和EXPERIENCE.LDT一样是"头部空壳+尾部真实数据"格式。应用彩虹岛编辑器操作，不要用二进制直接操作。

## 一天100级的原因
- 前100级几乎没有有效的任务经验系统
- 核心原因是EXPERIENCE.LDT曲线太陡（前期所需经验极低+后期极高）
- 升到Lv100只需约18,957,243原始经验
