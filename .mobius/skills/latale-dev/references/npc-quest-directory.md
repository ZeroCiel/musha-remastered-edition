## NPC关联任务查询方法

新增/修改任务时，如需查找某NPC已关联的任务：
1. 用编辑器打开QUEST_INFO_1.LDT
2. 搜索_NPC_Info1列=目标NPC名
3. 查看对应的_Quest_BaseLV、_Quest_Kind、_Quest_Next
4. 同地点+同NPC的任务往往是同一任务链

**注意：二进制LDT文件里NPC/Place字段存的是int32索引，实际文本只有编辑器导出TXT才有。**
所以对NPC的查询必须基于导出TXT，不能直接读二进制。

## 任务追加参考

追加任务到某NPC时参考步骤：
1. 确认NPC所在的地图（用本表查找）
2. 确认该NPC已有的任务BaseLV范围（从QUEST_INFO_1导出搜NPC名）
3. 确定_Quest_Next链上最后一个任务
4. 在QUEST_INFO_1追加新行（填NPC/Place/BaseLV/Next）
5. 在QUEST_REWARD_1追加对应行

## S1 的 NPC 信息

S1的NPC信息嵌在QUEST.LDT尾部string区（623KB），与对话文本混合，**没有独立的NPC名称索引表**。
S1 NPC.LDT只存NPC的功能事件配置（15列×300行），不存NPC名称文本。
如需S1的NPC任务对应关系，需编辑器打开S1的QUEST.LDT导出TXT后手动提取。
