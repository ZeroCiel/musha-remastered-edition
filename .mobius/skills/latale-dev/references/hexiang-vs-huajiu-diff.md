# 他乡端 vs 怀旧端 EFFECT.LDT 差异

## 文件位置
- 怀旧端：`D:\彩虹岛\resource\ROWID\DATA\LDT\EFFECT.LDT`
- 他乡端：`D:\LaTale\彩虹岛S2 他乡彩虹岛\解包目录\ROWID\DATA\LDT\EFFECT.LDT`

## 基础对比
| 项目 | 怀旧端 | 他乡端 |
|------|--------|--------|
| 文件大小 | 5.7MB | 8.0MB |
| 列数 | 70 | 70 |
| 行数 | 18,787 | 26,570 |
| 非零BuffID | 8,480 | 12,016 |
| 有效BuffID(1~999999) | 477个 | 565个 |

## 差异分析
- 他乡端多出约7,783行（+41%）
- 两个端共享的BuffID：**仅798个**（重合率20%）
- 怀旧独有BuffID：2,265个
- 他乡独有BuffID：3,213个
- EffectType分布相似但细节不同，他乡多出3,290个独有EffectType
- 两个端的EffectType TOP20基本一致（0, 77824, 19922945, 65536, 16777216, 805306672, 1等）

**结论：整体替换EFFECT.LDT极危险**——重合率仅20%，替换后他乡端大量新效果会丢失。

## 关键效果差异

### "爱丽丝的祝福"相关
| 效果名 | 怀旧端 | 他乡端 |
|--------|--------|--------|
| 爱丽丝的祝福 200%经验 | ✅ 存在 | ❌ 不存在 |
| 爱丽丝的祝福 100%经验(改后) | ✅ 改后存在 | ❌ 不存在 |
| 艾丽斯的祝福 40%经验(30分钟) | ✅ 存在 | ✅ 存在 |
| 暴走的爱丽丝图腾(固伤) | ❌ 不存在 | ✅ 存在 |

怀旧端的"爱丽丝的祝福 200%经验"（BuffID=7600）在他乡端没有对应行。删除EVENT_CHECK的活动后创角没有200%经验了但出现了"掉落100%艾丽丝的祝福"——怀疑BuffID=7600的效果本身绑定了掉落参数（改EffectValueType只改了经验倍率但没改掉落的系数，因为该effect的_StatusEffect或_EffectParameter字段可能同时控制经验和掉落）。

## 二进制搜索技巧

EFFECT.LDT中的字符串(_Name和_Description)以2B长度前缀+GBK编码存储在数据区后面的string区。直接用二进制搜索文本关键字定位：
```python
data.decode('gbk', errors='replace').find('爱丽丝')
```
返回的是解码后字符偏移。

注意：EFFECT.LDT的类型区（col_types）全部为0（非标准格式），但数据从标准的8716偏移开始。字符串区在标准数据区+行数×列数×4之后。读取字符串时先用2B小端无符号读长度，再用GBK解码。

## CREATION_INFO.LDT 特殊格式

与本端ROWID目录下其他LDT不同，CREATION_INFO.LDT的**标准头部（col=82, row=104）指向的数据偏移5588处全为0**。真正的数据从**偏移8716(0x220c)**开始。

该表二进制逐行读出来的_Class/_Gender值和编辑器TXT不一致，**改此表必须经过编辑器TXT**。安全流程：
1. 编辑器打开CREATION_INFO.LDT → 导出全表TXT
2. 在TXT中修改对应Class行的物品/技能/基础属性
3. 用ldt_writer.py写回LDT
