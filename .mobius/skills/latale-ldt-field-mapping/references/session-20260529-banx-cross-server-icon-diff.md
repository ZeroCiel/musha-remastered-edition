# BANX主图跨服对比（怀旧端 vs 他乡端）

## 对比方法（通用）

1. 分别读取两端 `ITEM_2.LDT` 的 `_Icon` 和 `_IconIndex` 字段
2. 统计每个 `IconFile` 在两端的最小/最大 `IconIndex` 和总图数
3. 差值 = 他乡端有而怀旧端无的 IconFile + 共同IconFile中多出的索引
