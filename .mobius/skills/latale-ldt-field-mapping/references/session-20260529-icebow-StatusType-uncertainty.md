## 写入方式

用户通过**彩虹岛编辑器**手动追加。编辑器导出格式为 `|` 分隔的126字段（含RowId）：
```
518160621|809|40|1|雪女冰弓（专用）|+35% 最小值/最大值 物理/魔法\n不可强化、镶嵌||10001101|174|151000|0|0|null|1|1|1|13|14|0|15|16|0|9|66|74|62|81|218|10|70|135|...
```

**注意**：编辑器中显示的第一列是 RowId（本例=518160621），但 ITEM_2.LDT 本身没有 _RowId 列。这是彩虹岛编辑器自带的显示格式。

## 教训

1. **不要二进制直接写入 ITEM_2** — 我的 Python 二进制写入（append到文件尾）被用户手动编辑覆盖掉了，数据未生效
2. **用户偏好手动** — 彩虹岛编辑器是唯一受信任的 ITEM_2 编辑方式
3. **列数差异** — S1 ITEM_2 (109列) ≠ S2 ITEM_2 (125列)，S2多了16列: _Use_Type, _StatusType5~8, _StatusValue5~8, _Specialeffect, _Seal_Min/Max_Cnt, _Colouring, _PatternClass, _PatternType, _Breakup, _Pet_Potential
4. **S1有 S2没有的列**：_NameColor
