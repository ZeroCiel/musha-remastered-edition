# ITEM_2 武器时装新增/修改指南

## 背景

此S2怀旧端（他乡包衍生物）**没有独立武器时装栏**。武器和真武器共用同一个装备槽位。所以新增的"武器时装"实际上是带属性的真武器。

## 武器字段参考值

参考已有武器"活动铅笔短剑"(行1619) 和 "冰原女猎手"系列，武器时装的字段配置：

### INT列 (前48列)

| 索引 | 字段 | 值 | 说明 |
|------|------|-----|------|
| 0 | _Category | 0 | 分类 |
| 1 | _Num | ItemID | 物品数字ID |
| 2 | _ColorID | 0 | 颜色 |
| 3 | _Name | GLString引用或0 | Name实际存为string在行后半段 |
| 4 | _Description | 0 | Description同理 |
| 5 | _Use_Type | 0 | 使用类型（0=一般） |
| 6 | _Icon | 1004 或类似 | 图标文件ID，可复用其他武器图标 |
| 7 | _IconIndex | 1 或类似 | 图标索引 |
| 8 | _GamePrice | 0 | 游戏币价格 |
| 9 | _CashPrice | 0 | 点券价格 |
| 10 | _CashCheck | 0/1 | 0=未上架商城 |
| 11~47 | 各种 | 多为0 | 状态值、限制等 |

### 字符串区域 (48*4之后)

行后半段（48*4=192偏移后）是`\x00`分隔的字符串序列：

1. 第一个有效字符串 = **道具名称**（如"活动铅笔短剑/"）
2. 第二个有效字符串 = **道具描述**（如"模范生用的铅笔短剑\\n注意!不能与战斗武器同时佩戴"）
3. 后续 = 其他文本字段

### 从鞋子改成冰弓（实战案例）

2026-05-29 尝试把"上位星云花语(鞋子)"行改名为"冰弓（活动）"并改成武器时装。

### 步骤
1. 用彩虹岛编辑器找到目标行（上位星云花语(鞋子)在行10766/10768）
2. 修改_Name为"冰弓（活动）"
3. 改_PosID1从8（鞋）→ 15（武器）
4. 添加物理/魔法攻击的StatusType/Value

### 遇到的问题
- GS日志报错格式等尚未确认——属性数值还在构思中（玩具级：物理+40%/魔法+40% 最小最大值）
- StatusType枚举值未知：不知道哪个Type编号对应物理攻击百分比、哪个对应魔法攻击百分比
- 需要通过彩虹岛编辑器查看已有带攻击属性的装备来逆向StatusType编号
- 彩虹岛编辑器新增行（行10768）的INT列全是乱值——可能是编辑器写入格式问题或该行原本不是正常数据行

### 经验
- 如果通过编辑器加行后INT列全乱，说明编辑器可能把数据写到了文件末尾非标准区域
- 更安全的方式：在编辑器内直接修改已有行的字段值，不改行结构

## 属性修改方法（物理/魔法攻击）

要添加攻击属性，需要设置_StatusType和_StatusValue系列列：

### 物理攻击
- _StatusType1 (22) = 1 (物理攻击力)？
- _StatusValue1 (23) = 数值

### 魔法攻击
- _StatusType3 (26) = ? (魔法攻击力)
- _StatusValue3 (27) = 数值

### 百分比数值
注意：百分比和固定数值的区分由_StatusType的高位决定。例如：
- _StatusType1 = 1（固定值）
- _StatusType1 = 某值 + 高位标记 = 百分比

**注意**：这些Status类型的枚举值尚未完全确认，需要通过彩虹岛编辑器查看已有带攻击属性的武器来逆向。

## 二进制修改步骤

1. 备份要修改的行（500字节）
2. 修改字符串区域：替换_Name字符串（等长或更短，多余字节填0）
3. 修改_PosID1：[15] = 15（本端武器）
4. 修改状态值列（StatusType1~8, StatusValue1~8）
5. 文件大小不变，直接覆盖写入
6. 恢复SPF包后启动GS测试

## 已知限制

- 行大小固定500字节，Name/Description字符串长度不能超过原串（或同步调整其他字段）
- ITEM_2.LDT文件末尾有额外数据（约593KB），不是标准行填充区。追加新行时需要确认是否写入了安全区域
- 本端武器时装极少（仅"活动铅笔短剑"等），新增后GS兼容性未知
- 彩虹岛编辑器是首选操作方式，二进制写是备选方案
