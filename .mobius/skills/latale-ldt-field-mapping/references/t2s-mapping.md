# 繁简转换映射表 (T2S)
用于彩虹岛LDT文本批量繁转简。约400+个常用简繁差异字。

## 使用方式
```bash
py -3 C:\Users\Administrator\Temp\fast_t2s.py
```

一键全自动扫描所有LDT文件。自动备份`.bak_trad`。

## 手动追加映射
如果发现游戏中仍有未转换的繁体字，编辑`C:\Users\Administrator\Temp\fast_t2s.py`中的`T2S`字典追加条目。

## 扫描结果（截至2026-05-27）
- 256个LDT文件中，62个包含繁体字
- 共316个不同的繁体字
- 最常见的繁体字（按文件数）：
  - 後(42), 乾(20), 級(14), 領(13), 愛(13), 學(13)
  - 機(12), 強(12), 體(12), 長(11), 黃(11), 場(11)

## 已知问题
- "後→后" 有歧义（"皇后"的"后"和"之後"的"後"都变成"后"）
- "乾→干" 有歧义（"乾燥"→"干燥"，"干杯"不变）
- 游戏专有名词（NPC名、地名）也可能被转换，大部分影响不大
- pack=1模式需要重新打包SPF；pack=0模式重启GS即可
- 关客户端重开才刷新文本缓存

## 验证方法
转换后用Python脚本扫描是否还有繁体字：
```python
import struct
with open('ITEM_1.LDT', 'rb') as f:
    data = f.read()
# ... 检查T2S中任一key是否出现在string列中
```
