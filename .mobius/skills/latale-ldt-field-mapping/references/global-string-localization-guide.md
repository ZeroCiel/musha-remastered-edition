## XLS文件修改方法

### 方法1: GBK二进制替换（推荐）
```python
with open("GLOBAL_STRING.xls", "rb") as f:
    raw = bytearray(f.read())
old = "骑士".encode("gbk")
new = "盾卫".encode("gbk")
raw = raw.replace(old, new)
with open("GLOBAL_STRING.xls", "wb") as f:
    f.write(raw)
```

⚠️ 注意：`\n` 在xls文件中存储为 `5C 6E`（两个字符：反斜杠+n），不是单个 `0A` 换行符。替换含换行的长文本时，xls里的换行必须是 `\\n`（双反斜杠n）。

### 方法2: 彩虹岛编辑器手动改
打开XLS文件→编辑对应ID行的_STRING字段→保存
