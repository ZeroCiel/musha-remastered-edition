# CLASS_STRING & ITEM_1 装备限制解码

## CLASS_STRING.xls (3列, 149行)

彩虹岛编辑器导出的 CLASS_STRING.xls 存储了职业名与位掩码(bitmask)的映射。

### 格式
- 列0: `_ID` — 行号
- 列1: `_Value` — 位掩码值(bitmask, 2的幂)
- 列2: `_String` — 职业名称(GBK)

### 位掩码结构
职业用2的幂位编码（bitmask）：
- 战士=1, 盾卫/骑士=2, 法师=4, 游侠=8, 督军=16, 双刀/剑斗士=32...
- 组合值如 战士系列(1+2+16+32...)、物理系列等

ID=92(`游侠 / 宝藏猎人系列`, bitmask=2199024305160) 说明游侠系列用了一个很大的bitmask值。

| 台服(他乡端) | 国服 | 说明 |
|-------------|------|------|
| 骑士 | 盾卫 | 基础职业 |
| 剑斗士 | 双刀 | 基础职业 |
| 圣殿骑士 | 圣殿骑士 | 派生名，保留 |

派生名（圣殿骑士/神骑士/恐惧骑士）虽然含"骑士"但不改为"盾卫"。

## ITEM_1 装备限制解码

### 字段位置 (0-based xls列)

| 列 | 字段 | 含义 |
|----|------|------|
| 39 | _Require1_Type | 限制类型1: 0=无限制, 1=职业限制 |
| 40 | _Require1_ID | 限制ID1: 对应CLASS_STRING的ClassID |
| 41 | _Require1_Value1 | 限制值1 (装备等级等) |
| 42 | _Require1_Value2 | 限制值2 |
| 43 | _Require2_Type | 限制类型2 |
| 44 | _Require2_ID | 限制ID2 |
| 45 | _Require2_Value1 | 限制值2-1 |
| 46 | _Require2_Value2 | 限制值2-2 |
| 47~54 | _Require3~4 | 同结构，3组限制 |

### 解码规则
- `_RequireX_Type` = 0 → 无限制（忽略此组）
- `_RequireX_Type` = 1 → **职业限制**，`_RequireX_ID` = ClassID
  - 1=战士, 2=盾卫, 3=法师, 4=游侠, 5=督军, 6=双刀, 8=圣殿骑士...

### 脏数据处理
编辑器位标记污染（常见值 65536=0x10000, 16777216=0x1000000, 2199024305160=0x20000002068）：
- 出现在 `_RequireX_Value1` 或 `_RequireX_Value2` 列时视为0
- 出现在 `_RequireX_Type` 列时该组应视为无限制

### 查询示例
```python
# 在ITEM_1.xls中查找"雪女冰弓"（_Name=col4）
# R1: type=0 id=0 val1=0 val2=0 → 无限制
# R2: type=1 id=1 val1=脏数据 val2=0 → 职业限制: 战士(ClassID=1)
```

### ITEM_1 xls 读取注意
- ITEM_1有109列，编辑器导出的TAB分隔文本
- _Name(col4) 是直接中文名（不像S1版的索引ID）
- _Type(col14)=1, _SubType(col15)=1 是普通装备
- _PosID1(col16)=13 武器槽位（本端版本）

## SKILL_TXT 本地化

SKILL_TXT.xls (4列: _ID, _Name, _Description, _DisableDescription) 是技能名称/描述/学习条件表。

### 台服→国服映射（已验证）
| 台服 | 国服 | 出现次数 | 示例 |
|------|------|---------|------|
| 配戴 | 佩戴 | 16处 | "配戴盾牌时可使用" → "佩戴盾牌时可使用" |
| 技能资讯 | 技能信息 | 若干 | 修改器/编辑器导出已自动转换 |
| ※技能资讯※ | ※技能信息※ | 大量 | |
| ※效果※ | ※效果※ | 一致，不改变 | |

### 无需变更的台服用词
| 台服 | 说明 |
|------|------|
| 初始化 | 技能初始化/组合初始化，国服也用"初始化" |
| 功能 | 如"攻击功能"，国服同样用此词 |
| 限制等级 | 部分描述中用，GS客户端显示已自动国服化 |
| 需要技能点数 | 同国服用语 |
