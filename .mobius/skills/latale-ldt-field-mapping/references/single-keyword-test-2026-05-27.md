# 单关键词分步测试：愛麗絲→爱丽丝 (2026-05-27)

## 测试模式

用户指定改一个特定关键词（愛麗絲→爱丽丝），而不是一整套繁简映射表。改完打包→重启GS→确认不炸→再推进。

## 流程

1. **仅NPCTALK.LDT先试水**（用户说"试试怎么炸"）
2. 用 `ldt-find-replace.exe replace` 做了NPCTALK.LDT的替换：1403处
3. GS没炸 → 用户确认"没有炸，但也没测出来效果"
4. 继续搜其他文件中的"愛麗絲"：7个文件87处
5. 额外发现"艾丽丝"（已经是简体但用户说改成"爱丽丝"）：ITEM_2.LDT 8处
6. 全部改完 → 打包 → GS还是没炸

## 关键发现

- 二进制等长替换（bytearray.replace）改LDT是安全的。改"愛麗絲"→"爱丽丝"（各3个汉字，GBK各6字节）没有引起GS崩溃
- "艾丽丝"→"爱丽丝"从技能记忆来看是用户要求的另一个实体名称修正
- 不崩≠有效果——用户说"没测出来效果，只是保证能玩"，说明GS能跑但游戏中这些文本是否显示为简体可能还要进游戏验证
- 这就是"试试怎么炸"的策略：先改一个关键词→打包→GS不崩→继续，GS崩了→回退→缩小范围再试
