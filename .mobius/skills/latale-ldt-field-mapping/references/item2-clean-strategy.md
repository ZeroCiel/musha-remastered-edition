## 限时版筛选规则（按优先级）
1. 有永久版的 → 限时版全部删除，留永久版
2. 只有限时版没有永久版的 → 不动（后续改成永久或删）
3. 同基础名多天数版本 → 只留最长天数

## GS crash from CashCheck 0→1

当把ITEM_2中道具的CashCheck从0改为1后，GS启动时会完整加载该道具的全部数据列，可能暴露之前被隐藏的坏数据（65536/16777216等位标记污染）。

**预防**：改CashCheck 0→1前，先搜索LDT中所有值为65536/16777216的int列并清0。

## 批量改CashCheck安全流程
1. 仅改int字段（CashCheck在列10，固定偏移`行起始+10*4`）
2. 用道具名GBK搜索定位行（不要用RowId当行号）
3. 行起始 = `DATA_OFF + ((match_pos - DATA_OFF) // ROW_SIZE) * ROW_SIZE`
4. 改完后的LDT大小应与原版一致

## BayServer SIGSEGV 教训
- **不能直接用RowId当二进制行号**（编辑器RowId和LDT行号无关）
- 改LDT字符串字段必须**等长**（短了用0x20填空，不要用0x00）
- 非法GBK字节（0x9b/0x9c/0x85等）需逐字节过滤
- 安全做法：用道具名GBK在二进制中搜索定位，只改int字段（固定4字节）
