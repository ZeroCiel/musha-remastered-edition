# CROP.LDT 文件对比方法

## 用途
CROP.LDT是种植系统数据表。当需要对比不同端的CROP数据时使用。

## 快速方法
直接用文件大小对比：
```
ls -la path/to/crop.ldt
```

如果文件大小相同（如15998字节），内容差异极小，通常是繁简转换导致。

## 2026-05-29 会话记录

### 场景
用户将CROP.LDT放到桌面（来源：解包目录），要求对比当前端（D:\彩虹岛\resource\）和桌面版。

### 结果
- 文件大小完全一致（15998字节）
- 头部一致（unk=0, col_count=37, row_count=37）
- 内容有48个字节的差异，分24组，每组2字节
- **差异全是繁简转换**（仅4个字）：

| 桌面（简体） | 当前端（繁体） | GBK |
|------------|--------------|-----|
| 么样 | 麽样 | c3b4d1f9 → f7e1d1f9 |
| 啰 | 罗 | 86aa → c2de |
| 后 | 後 | baf3 → e1e1 |
| 伙 | 夥 | bbef → e2b7 |

### 结论
桌面版CROP.LDT是简体版，当前端的是繁体版。结构和数据完全一致，只有这4组繁简转换差异。
