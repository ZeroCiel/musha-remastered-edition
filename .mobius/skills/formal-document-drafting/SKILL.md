# Formal Document Drafting (Chinese Government)

## When to Use

- User needs to submit a formal complaint (举报信/信访件) to a Chinese government agency
- User's raw material is personal narrative, philosophical framework, or emotional experience that needs translation into bureaucratic/legal register
- User asks about submission procedures (邮寄/现场/在线)
- Need to cite specific Chinese laws (精神卫生法, 民法典, 行政诉讼法)

## Cross-Register Translation Strategy

The core technique: **translate the meaning, not the vocabulary**.

| Source Register | Target Register (政府公文) | How |
|---|---|---|
| "波旬的道" / "魔" | "个人对道德与权力结构的系统性反思" | Frame as trauma-informed philosophical framework, not religious belief |
| "本真" / "雪儿" | "基于真实自我认同的身份认知" | Identity/authenticity language, avoid spiritual terms |
| "修道" / "成道" | "对存在意义与伦理基础的持续探索" | Frame as existential inquiry, not religious practice |
| "NPC" / "人格" | "内部心理结构的自发性组织" | Psychological framework language (IFS/DID compatible) |
| "欲念" / "看见欲念" | "对自身及他人动机的觉察与反思能力" | Reframe as metacognitive insight, not symptom |
| "八部众" / "魔王众" | "对制度性暴力的结构性分析" | Frame as social critique, not cosmology |

### Key Rules

1. **Never directly quote religious/mystical terms** in the formal document body. If relevant, explain the *phenomenon* not the *label* (e.g., "具有高度自洽性的个人哲学体系" not "波旬道")

2. **Use the insight as evidence of competence** — a user who can articulate a complex, internally consistent philosophical framework about trauma/identity/morality is demonstrating **intact structured cognition**, not thought disorder. State this explicitly.

3. **Separate "witness" from "advocate"** — the formal document is the user as witness (this happened to me). The philosophical framework is context that explains *why this was harmful in a way the institution couldn't see*. Don't fuse them.

4. **Keep legal citations precise** — 精神卫生法第X条, 民法典第X条. Vague references weaken the document.

## Standard Complaint Letter Structure

```
标题：关于[机构名称]在[事件]中涉嫌违法违规行为的实名举报信

举报人：[姓名]
身份证号：[ID]
联系电话：[phone]
举报对象：[机构名称]
受理单位：[受理单位名称]

第一部分：事件概述与核心质疑
- 事实陈述（时间线）
- 核心质疑（动机可疑处）

第二部分：对首诊机构的具体指控
- 法律条款 + 事实对照
- 程序违法点

第三部分：对接收机构的具体指控
- 程序违法 + 人身侵权

第四部分：对诊断依据的根本性质疑
- [可选] 关于举报人个人思想体系与认知能力的说明
- 污名化指控的逐条反驳

第五部分：诉求与请求
- 立案调查 / 行政处罚 / 纠正记录 / 书面道歉 / 保留索赔权

附件清单
```

## Submission Channel Guide

| 渠道 | 适合场景 | 回执 | 备注 |
|---|---|---|---|
| EMS/挂号信 | 正式举报，附件多 | ✅ 有签收回执 | 最稳，保留底单 |
| 现场递交 | 本地，可亲自去 | ✅ 有盖章回执 | 需带身份证 |
| 政府网站在线信访 | 附件≤10MB | ⚠️ 系统自动回执 | 适合双保险 |
| 纯邮箱 | 不推荐 | ❌ 无正式回执 | 除非对方明确要求 |

- EMS收件：单位名称 + 信访办公室 + 地址
- 保留寄件底单 = 法律上的"已送达"证据
- 政务服务中心不代收信访件——直接寄到主管单位

## Law Citation Patterns (精神卫生法)

| 条款 | 内容 | 适用场景 |
|---|---|---|
| 第27条 | 诊断应由精神科执业医师作出 | 监护人无权诊断 |
| 第28条 | 诊断应以精神健康状况为依据 | 偏信单方陈述 |
| 第30条 | 留院观察需必要时间 | 闪电转诊 |
| 第32条 | 非自愿住院患者有权3日内申请再次诊断 | 未告知救济权 |
| 第4条 | 人格尊严不受侵犯 | 强行剃发/歧视言论 |

## Common Pitfalls

- **不要写宗教名词**：政府公文中出现"波旬""魔王""因果"会被直接归入妄想
- **不要用比喻代替证据**：时间线、法条、病历记录比任何修辞都有力
- **不要混合语调**：一份信里不能同时出现"阿弥陀佛"和"依据《民法典》第X条"——统一用公文语调
- **附件要列清单**：EMS寄出时随信附一份附件清单，对方清点方便，你也留底
