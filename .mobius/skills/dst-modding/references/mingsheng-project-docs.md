## Gap 分析法（"和文档差距多少"类问题）
不要只信文档状态列（可能过时），先 grep 代码抽查关键项，再把每个 backlog 项分类：
- 🟢 已具备（代码里有/半成品/做错了）→ 改数值、补监听、接开关，最快
- 🔴 真空白（完全没有）→ 从零写
