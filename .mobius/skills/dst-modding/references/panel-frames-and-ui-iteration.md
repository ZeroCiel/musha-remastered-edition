# DST 面板绘制：框体/描边 + 与用户的 UI 迭代协作

## 空心边框怎么画
- `Image("images/global.xml", "square.tex")` 是**实心色块**，不能直接做空心描边。
- 要"框"时：用 4 条细长实心条拼矩形（上/下横条 + 左/右竖条），条厚 3~6px，`SetTint` 上色。
- "背景板 + 框体" = 两层：`bg`（整块半透明底色，SetTint 上色）+ `frame`（4 条描边线）。
  描边建好后先加进 children，再叠 `bar`/`barw`/文字。
- 行内装饰条（顶部高亮/标记条）要和框线上沿错开几像素，否则重叠。例：框线上沿 y=32 时，
  顶部标记条下移到 y=26。
- 宽度类参数抽成局部常量（如 `ROW_W = 840`），底框/描边/标记条共用 → 改尺寸只改一处。
- 动态变色：把 4 条描边存进 `row.frame = {line1..line4}`，刷新时按行类型循环 `SetTint`。

## 与用户的 UI 迭代协作（Musha/明生面板实测）
- 用户按像素给数值（"右移20""上移8""加长12""往左移4"）。**一次收齐、一次改完**，别让他逐条挤。
- 滑入/动效用 Widget 自带 `uianim:MoveTo(from, to, dur, ondone)`；逐行错开 0.08s。
  动画起始点要带上行的目标偏移（`from_x = target_x + 320`，终点用 target_x），否则会落错位置。
- 每次改完写进 backlog / SSOT 文档（如 `musha-backlog.md`），防断电、跨会话可续。
- **范围歧义必须先确认**：用户说"加框框"时，可能是"每一项一个框"，也可能是"整体一圈外框"，
  两者实现完全不同。先 clarify 给 2~3 个选项，别猜——猜错要整段重写。
  实测：把"每个任务都要有框"误做成整体外框，用户澄清后要求撤销重做。
- 用户描述可以极短、省略主语（"框体——我指的是每个任务都要有 除了背景板"）。
  默认把"任务/行/框"理解为**列表里的每一项**，而不是整个容器。
- 改错方向时用户会直接说"理解反了"，照做撤销+重做即可，不用解释一堆。
